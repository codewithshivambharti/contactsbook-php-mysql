# ContactsBook – PHP & MySQL Project

## 📌 Project Overview

ContactsBook is a web-based contact management application developed using PHP and MySQL. It provides users with a simple and organized platform to register, log in, manage their personal profiles, and maintain their contacts efficiently.

The application includes essential features such as user authentication, profile management, contact management, and image uploading. It demonstrates practical implementation of PHP programming, MySQL database connectivity, session management, and CRUD operations.

## 🚀 Features

### 1. User Authentication
- User Registration and Login.
- Secure User Logout.
- User Authentication and Authorization.
- User Account Management.

### 2. User Profile Management
- View User Profile.
- Edit and Update Profile Details.
- Change or Reset Password.
- Upload and Update Profile Picture.

### 3. Contact Management
- Add New Contacts.
- View Contact Details.
- Edit and Update Existing Contacts.
- Manage Personal Contact Information.
- Upload Contact Photos.
- Activate and Deactivate Contacts.
